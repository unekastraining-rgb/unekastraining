# UNIVERSAL_LEARNER_JOURNEY — 2P-33

Learner-facing roles around **one** Universal Learning Engine.

```text
ENTER STUDY HAUL
      ↓
UNDERSTAND WHAT TO DO
      ↓
START / CONTINUE LEARNING
      ↓
LEARN THROUGH THE APPROPRIATE EXPERIENCE
      ↓
COMPLETE THE ACTIVITY
      ↓
SEE WHAT HAPPENED
      ↓
CONTINUE TO THE NEXT STEP
      ↓
SEE GROWTH
      ↓
RETAIN THROUGH LUCKY
```

The learner does not need to know CORE / SIX / Orchestrator / Adaptive internals.

---

## Experience roles

| Experience | Learner job |
|------------|-------------|
| **HUB** | Home — choose what to work on |
| **CORE** | Capture, organize, understand material |
| **SIX** | Learning techniques / interventions |
| **TUTOR** | Conversational teaching |
| **ADAPTIVE** | Personalized next-step progression |
| **ACTIVITY** | Perform the actual learning task |
| **GROWTH** | Understand progress and demonstrated mastery |
| **LUCKY** | Retain learning after progression |
| **MATERIALS** | Source / context for learning |
| **COURSE / LMS** | Optional academic context |

These are **experiences** around one engine — not separate products with separate mastery/evidence.

---

## Canonical truth (unchanged)

| Concern | Owner |
|---------|--------|
| Diagnosis | Orchestrator |
| Progression | Adaptive |
| Teaching | Tutor |
| Retention | LUCKY |
| Mastery truth | ConceptMastery |
| Evidence truth | LearningAttempt |
| Presentation HOW | Teaching Style |
| Intent WHY | Learning Intent |
| Context (read-only) | Universal Learner Context |

Course/LMS and Materials never become universal learning truth or evidence by themselves.

---

## Action language (context-sensitive)

| Situation | Preferred label |
|-----------|-----------------|
| No ACTIVE Adaptive run | **Start learning** |
| ACTIVE Adaptive run | **Continue learning** |
| After activity success in Adaptive | **Continue** / next step (existing) |
| Needs practice | **Practice again** / Try again (existing) |
| Informational progress | **View progress** |
| Assignment entry | Start/Continue learning (optional subtitle: study this assignment) |
| Retention | **Retain** / Open Lucky retention |

Do not say Start when resuming. Do not say Continue when nothing is resumable. Do not say Completed for Abandoned. Do not say Mastered unless the mastery model supports it.

---

## Return-path matrix

| From | Through | Back to |
|------|---------|---------|
| Hub | Adaptive → Activity | Adaptive → Growth / Hub |
| CORE | Adaptive → Activity | Adaptive (optional Back to notebook) |
| SIX (direct) | SIX activity | SIX / Hub |
| SIX (Adaptive-bound) | SIX activity | Adaptive |
| Tutor | Session | Learner-selected next (Hub / Growth / Adaptive) |
| Growth | Adaptive → Activity | Growth / Hub |
| Material | Adaptive / Tutor / CORE | Adaptive / Hub |
| Assignment | Study learning → Adaptive | Adaptive / Hub |
| Activity (bound) | Complete | Adaptive (AdaptiveReturnStrip) |
| Adaptive COMPLETED | Soft Lucky handoff | Lucky → existing Lucky flow |
| Lucky | Retention items | Lucky / Hub |

Preserve all valid existing paths. Add missing affordances only when they do not create a second navigation architecture.

---

## Integrity

Views and launches do **not** create LearningAttempt or ConceptMastery:

Hub view · Growth view · CORE open/edit · Material open · Course/LMS sync · Assignment view · Start/Continue click · Adaptive view · SIX view · Tutor view · Learner Context view

Only legitimate learning interactions produce authoritative evidence via existing producers.
